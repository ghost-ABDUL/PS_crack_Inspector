PS 균열 검사기 사용설명서
========================

타일 표면을 8방향 조명으로 촬영해, 실제 균열인지 균열처럼 보이는 무늬·스티커인지 판정합니다.


1. 준비
--------
- Windows 10 / 11 (64비트)
- 검사 장치: 카메라(USB) + LED 컨트롤러(아두이노, USB)
- 처음 설치할 때만 필요: ChArUco 보드 인쇄물, 지름 30mm 크롬(거울) 볼

설치: 받은 압축 파일을 원하는 곳(예: 바탕화면, D:\PS_Inspector)에 풀면 끝입니다.
      ※ C:\Program Files 안에는 풀지 마세요. 캘리브레이션·검사 결과를 저장하지 못합니다.

실행: 폴더 안의 PS_Inspector.exe 를 더블클릭합니다.
      (처음 실행 시 Windows 보안 경고가 나오면 '추가 정보' → '실행'을 누르세요.)


2. 처음 설치할 때 (한 번만, 약 30~40분)
-------------------------------------
화면 왼쪽의 단계를 위에서부터 차례로 진행합니다. 각 화면 오른쪽 노란 상자에
'다음에 할 일'이 항상 표시되니 그대로 따라 하면 됩니다.

  0. 장치 연결            [자동으로 찾아 연결] 한 번 (약 30초, LED가 깜빡이는 것은 정상)
  1. 카메라 캘리브레이션   보드를 여러 각도로 15~25장 + 바닥에 놓고 1장 → 계산
  2. LED 위치 캘리브레이션 크롬볼을 4~5곳에 놓고 테두리 클릭 → 촬영 → 계산
  3. 기준 촬영            불 끄고 흰 종이를 깔고 촬영

  왼쪽 단계 표시:  ● 완료(초록)  ● 다시 필요(주황)  ● 필요(회색)
  앞 단계를 다시 하면 뒤 단계가 자동으로 '다시 필요'로 바뀝니다.

  다시 해야 하는 경우
  - 카메라·렌즈·초점을 바꿨다        → 1, 2, 3 단계
  - LED를 옮겼다                    → 2, 3 단계
  - 장치를 다른 곳으로 옮겼다, 결과가 이상하다 → 3 단계


3. 평소 검사
------------
프로그램을 켜면 자동으로 장치에 연결되고 '4. 균열 검사' 화면이 열립니다.

  ① 방 조명을 끕니다 (창문 빛도 가리기).
  ② 타일을 스테이지에 놓고, 미리보기에서 화면 가운데에 오게 맞춥니다.
  ③ [촬영 + 판정]을 누릅니다 (약 30초, 그동안 장치와 타일을 건드리지 마세요).
  ④ 결과:
       '균열이 있습니다'      — 빨간색 글씨, 균열 위치가 빨갛게·노란 네모로 표시
       '균열 없음 — 무늬입니다' — 초록색 글씨
  ⑤ 다음 타일은 [새 검사]를 누르고 타일을 바꿔 놓습니다.

  - 지난 검사는 화면 아래 목록을 클릭하면 다시 볼 수 있습니다.
  - 결과 그림: ps_out\(이름)\fast\verdict.png
  - [자세한 분석 그림]: 판정 근거(표면 방향, 균열 점수 등)


4. 판정에 대해 알아둘 점
------------------------
- 실제 균열은 깨진 면 때문에 표면 방향이 미세하게 꺾입니다. 무늬·스티커·그림은
  평평한 면 위의 색 변화라 꺾이지 않습니다. 이 차이로 판정합니다.
- 아주 가늘고 조각이 전혀 어긋나지 않은 균열은 '무늬'로 판정될 수 있습니다.
- 표시되는 균열 길이는 판정된 구간만의 길이로, 실제 균열보다 짧게 나올 수 있습니다.
- 방 조명이 켜져 있으면 정확도가 떨어집니다 (화면 기록에 '주변 빛' 경고가 표시됩니다).


5. 문제 해결
------------
- '장치를 찾지 못했습니다'
    USB 케이블을 다시 꽂고 [자동으로 찾아 연결]. 다른 프로그램(카메라 앱, 아두이노 IDE 등)이
    카메라나 포트를 쓰고 있으면 닫으세요.
- 카메라를 잘못 골랐다
    0단계 '직접 지정'에서 카메라 번호를 바꿔 [이 설정으로 연결].
- 기준 촬영에서 빨간 영역(포화)이 보인다
    [어둡게]로 노출을 낮추세요.
- '주변 빛이 들어왔습니다' 경고
    조명을 끄고 다시 촬영하세요.
- 자가 진단: 명령 프롬프트에서  PS_Inspector.exe --selftest
    연결 → 촬영 → 판정을 자동으로 한 번 실행하고 결과를 ps_app_log.txt 에 남깁니다.

문의 시 폴더 안의 ps_app_log.txt 파일을 함께 보내 주세요.
